# Java Mini Projects

This repository contains a collection of Java mini projects created to practice object-oriented programming, GUI development and basic application logic.

## Projects

### Calculator
A simple calculator application built with Java.

### Guess The Number
A console-based game where the user tries to guess a randomly generated number.

### Snake Game
Classic Snake game implemented in Java.

### Space Invaders
Simple arcade-style game inspired by Space Invaders.

### Tetris
A basic Tetris-style game built in Java.

## Technologies Used

- Java
- Object-Oriented Programming
- Java Swing / GUI
- Basic algorithms
- Game logic

## Purpose

The purpose of this repository is to demonstrate my Java learning progress and practical understanding of programming fundamentals.


## How to Run

1. Clone the repository:

```bash
git clone https://github.com/angrytomm/java-practice-projects.git
```

2. Open the project in IntelliJ IDEA or another Java IDE.

3. Choose one of the project folders, for example `Calculator`, `GameSnake` or `Tetris`.

4. Find the file that contains the `main` method.

5. Click **Run** to start the project.
